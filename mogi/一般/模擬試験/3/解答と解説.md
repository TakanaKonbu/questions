# 一般知識 模擬試験 第3回 解答と解説

## 【問1】 正解：①
［元データ：過去問第58回 問1準拠］
(a) 正：中間圏界面（高度約80〜90km）では、夏極側で強い上昇流による断熱冷却のため夏極（約−130℃）の方が冬極（約−70℃）より低温になる。よって「夏極より冬極の方が高い」は正しい。

## 【問2】 正解：③
［元データ：過去問第59回 問2類題］
全水蒸気量 = 2×12 + 1×3 = 27 g。全乾燥空気質量 = 3 kg。混合比 = 27 / 3 = 9.0 g/kg。正解は③。

## 【問5】 正解：②
［元データ：過去問第58回 問5準拠］
(b) 誤：大気の窓領域は水蒸気やCO2による赤外線吸収が『最も弱い』波長帯である。
(c) 誤：放射平衡温度（約-18℃）は温室効果を考慮しない値であり、地表の実気温（約15℃）より低い。

## 【問6】 正解：③
［元データ：過去問第58回 問6準拠］
(b) 誤：コリオリパラメータ f = 2Ωsinφ は緯度φの正弦に比例するため赤道で『ゼロ』、極で『最大』となる。
(c) 誤：地表面付近の境界層では摩擦力が働くため地衡風バランスは『成立せず』、風向が低気圧側に傾く。
(d) 正：大気中のエアロゾル粒子は凝結核や氷晶核として雲粒形成に不可欠な役割を果たす。

## 【問7】 正解：②

## 【問12】 正解：④

## 【問14】 正解：⑤
［元データ：過去問第57回 問14準拠（修正済）］
(a) 誤：気象業務法第15条第2項により、通常の『気象警報』発表時の知事から市町村長への通知は努力義務（『通知するよう努めなければならない』）。特別警報の場合のみ通知義務となる。
(b) 誤：気象業務法第15条の2の通報指定機関は『市町村長、警察官、海上保安官』であり、消防機関（消防官）は明記されていない。
(c) 誤：気象業務法第23条により、いかなる緊急時であっても気象庁以外の者が警報を発表することは禁止されている。
(d) 正：気象業務法第15条の2の規定通り正しい。
