# 専門知識 模擬試験5 解答と解説

【問1】

**正解：②（正 正 正 誤）**

(a) 正：気温観測用の電気式温度計（白金測温抵抗体）は、直達日射や周囲の地面・構造物からの赤外放射熱の影響を遮断するため、通風電動ファンを備えた二重円筒構造の強制通風筒内に感部を格納して観測されます。
(b) 正：全天日射計は、太陽から直接届く「直達日射量」と、大気分子や雲・エーロゾルによって散乱されて天空全体から届く「散乱日射量」の合計である水平面全天日射量を測定します。
(c) 正：寒冷地では雪が受水口に積もって計測口を塞いだり昇華したりするのを防ぐため、受水口ヒーターや電気加熱器、温水循環装置を内蔵した雨雪量計が使用されます。
(d) 誤：海面更正気圧（$P_0$）は、測器の設置高度（現地標高 $z$）と現地気圧（$P$）だけでなく、観測所から仮想的に海面まで伸ばした空気柱の「平均気温」を用いて測高公式により算出されます。気温によって空気密度が大きく変化するため、観測時の気温を無視することはできません。「観測時の気温は考慮されない」とする記述は誤りです。

【問2】

**正解：③（正 誤 正）**

(a) 正：ドップラーレーダーは、送信した電波が降水粒子に反射して戻ってくる際、粒子の運動によって生じるドップラー偏移（周波数のズレ）を検出することで、レーダーのビーム方向（視線方向）の相対速度成分を測定します。
(b) 誤：単一のドップラーレーダーで直接観測できるのは「視線方向の1次元速度成分」のみです。風が水平一様であると仮定するVAD法（速度方位表示法）などの仮定を置くか、異なる位置にある複数のドップラーレーダーの視線速度を合成（デュアルドップラー合成）しなければ、完全な3次元風速ベクトルを決定することはできません。「特別な仮定を置くことなく完全に決定することができる」とする記述は誤りです。
(c) 正：気象庁のメソ数値予報モデル（MSM）や局地モデル（LFM）では、ドップラーレーダーの視線速度データを変分法等のデータ同化手法によって取り込み、下層の収束・発散や水蒸気流入パターンの初期値精度を大幅に向上させています。

【問3】

**正解：①（正 正 正）**

(a) 正：GPSゾンデはゴム気球に吊り下げられて上昇しながら、搭載された気圧計・温度計・湿度計で各大気層の物理量を直接測定し、内蔵GPS受信機による位置情報の追尾から高精度の水平風向・風速を算出します。
(b) 正：通常は高度とともに気温が低下しますが、高度とともに気温が上昇する気層を「逆転層」と呼びます。逆転層内では静的安定度が極めて高く、上昇気流が抑制されるため、下層からの対流活動や汚染物質の拡散を遮る「蓋（リッド）」の役割を果たします。
(c) 正：状態曲線（エマグラム）において、気温 $T$ と露点温度 $T_d$ の差（湿数 $T - T_d$）が概ね3℃以下と小さい領域は相対湿度が約80〜100%に達しており、層雲や高層雲などの雲（凝結層）が存在する可能性が極めて高いと判断されます。

【問4】

**正解：③（正 誤 正）**

(a) 正：水平スケールが数十km以上の大規模な大気運動（全球モデルGSMなど）では、鉛直加速度が重力や鉛直気圧傾度力に比べて無視できるほど小さいため、静力学平衡（静力学方程式系）が良好に成り立ちます。
(b) 誤：メソモデル（MSM：格子間隔5km）や局地モデル（LFM：格子間隔2km）などの高解像度モデルでは、個々の積乱雲に伴う急激な鉛直加速度（数m/s〜数十m/sの上昇流・下降流）を表現する必要があるため、静力学近似を用いず鉛直方向の運動方程式を直接解く「非静力学方程式系（JMA-NHM等）」が採用されています。「静力学近似を前提とした方程式系が用いられている」とする記述は誤りです。
(c) 正：微分方程式を格子差分法で解く際、波や風が1タイムステップの間に隣の格子を超えて伝播すると数値的な計算爆発（発散）を起こします（CFL条件）。そのため、空間格子間隔を細かくするほど、時間積分の刻み幅（$\Delta t$）を比例して短くしなければなりません。

【問8】

**正解：④（正 正 誤 正）**

(a) 正：温帯低気圧が傾圧不安定波として発達する初期段階では、上空の気圧の谷の前面（上昇流域）に位置する前線帯に伴う雲バンドが、極側（北側）に向かって弓状・ドーム状に盛り上がって見え、これを「バルジ（雲の膨らみ）」と呼びます。
(b) 正：衛星水蒸気画像（6.7μm帯）は対流圏中上層の水蒸気分布を捉えます。赤外線が水蒸気によってあまり吸収されず下層から届く「暗域（黒い領域）」は乾燥した下降気流域を示し、「明域（白い領域）」は湿潤な上昇流域や上層雲域を示します。

(d) 正：低気圧が最盛期を迎えて閉塞すると、雲バンドは低気圧中心の周囲を渦巻き状に取り囲む「コンマ状（コンマ雲）」となり、低気圧の中心は寒気領域内に孤立して衰弱に向かいます。

【問9】

**正解：①（正 正 正 正）**

(a) 正：偏西風（ジェット気流）の南北蛇行が極端に大きくなると、南へ垂れ下がったトラフ（気圧の谷）がちぎれて本流から切り離されます。このようにして形成された寒気を伴う低気圧を「寒冷渦（切離低気圧 / カットオフ低気圧）」と呼びます。
(b) 正：寒冷渦は対流圏中上層（500hPa面など）で渦度が強く明瞭な低気圧性循環を形成します。上空に強い寒気（−20℃〜−30℃以下）が居座るため、大気の鉛直安定度が著しく低下します。
(c) 正：寒冷渦の前面（南東側〜東側）では、上空寒気の先端と下層の暖湿気流の合流が起き、鉛直シアと強い大気不安定が重なって活発なスーパーセルや線状降水帯などの積乱雲群が発生し、落雷・降雹・大雨・突風が集中します。
(d) 正：寒冷渦は偏西風の本流から切り離されているため指向流が弱く、移動速度が極めて遅いか停滞（ブロッキング）します。そのため、同じ地域に数日間にわたって断続的な激しい雷雨や荒天をもたらします。

【問10】

**正解：⑤（誤 正 正）**

(a) 誤：台風の発生には「海面水温26〜27℃以上」とともに、渦を巻くための「コリオリ力」が不可欠です。赤道直下（緯度0度）ではコリオリパラメータ（$f = 2\Omega\sin\phi$）が0となるため、渦度を集積できず台風は発生できません。台風は通常、十分なコリオリ力がある緯度5度から20度付近の熱帯海域で発生します。「赤道直下で最も頻繁に発生する」とする記述は誤りです。
(b) 正：台風の中心核（目および壁雲周辺）では、活発な積乱雲群の中で放出される凝結潜熱により周囲よりも著しく気温が高くなる「暖気核（ウォームコア）」が形成されます。暖気核による昇温偏差（周囲との温度差）は対流圏上層（300〜200hPa付近）で最大となります。
(c) 正：台風による高潮の要因には、中心気圧の低下に伴って海面が吸い上げられる静力学的な「吸い上げ効果」（中心気圧が1hPa低下すると海面が約1cm上昇）と、強烈な暴風によって海水が海岸や湾奥に押し寄せられて水位が上昇する動力学的な「吹き寄せ効果」の2つがあります。

【問12】

**正解：④（ME: -1.0℃, RMSE: 1.6℃）**

各日の誤差（予測値 $-$ 実測値）を計算します。
- 1日目：$20.0 - 21.0 = -1.0$ ℃
- 2日目：$22.0 - 23.0 = -1.0$ ℃
- 3日目：$25.0 - 24.0 = +1.0$ ℃
- 4日目：$23.0 - 24.0 = -1.0$ ℃
- 5日目：$20.0 - 23.0 = -3.0$ ℃

**平均誤差（ME）**：
$$\text{ME} = \frac{(-1.0) + (-1.0) + 1.0 + (-1.0) + (-3.0)}{5} = \frac{-5.0}{5} = -1.0 \text{ ℃}$$

**二乗平均平方根誤差（RMSE）**：
各日の誤差の二乗を計算します。
$$(-1.0)^2 = 1.0$$
$$(-1.0)^2 = 1.0$$
$$(+1.0)^2 = 1.0$$
$$(-1.0)^2 = 1.0$$
$$(-3.0)^2 = 9.0$$
二乗和 $= 1.0 + 1.0 + 1.0 + 1.0 + 9.0 = 13.0$
二乗平均誤差（MSE）$= \frac{13.0}{5} = 2.6 \text{ ℃}^2$
$$\text{RMSE} = \sqrt{2.6} \fallingdotseq 1.61 \text{ ℃}$$

したがって、④の「ME: -1.0℃, RMSE: 1.6℃」が正解です。

【問15】

**正解：⑤（正 正 正 誤）**

(a) 正：正のインド洋ダイポールモード現象（IOD）が発生すると、赤道インド洋において東風偏差が強まり、西部（アフリカ東岸沖）で暖水が蓄積して海面水温が平年より高くなり、東部（インドネシア沖）では冷水の湧昇により海面水温が平年より低くなります。
(b) 正：東部インド洋の海水温低下に伴い、インドネシア付近では対流活動が抑制されて下降気流が卓越するため、インドネシアやオーストラリア西部等で著しい少雨・干ばつや森林火災が発生しやすくなります。
(c) 正：熱帯域の対流活動偏差に伴う熱源の変動は、対流圏上層の偏西風ジェット沿いに定常ロスビー波を励起・伝播させ（シルクロードパターンなど）、チベット高気圧や太平洋高気圧の勢力に影響を与え、日本の夏の猛暑や日照時間の増加をもたらします。
(d) 誤：インド洋ダイポールモード現象と太平洋のエルニーニョ・ラニーニャ現象は独立した海洋・大気変動ですが、ウォーカー循環の変動などを通じて相互に影響を及ぼし合っており、同時に発生することがあります。例えば1997年や2019年には強力な正のインド洋ダイポールモード現象とエルニーニョ的傾向が重なり、世界的な異常気象をもたらしました。「排他的な現象であり、同時に発生することは決して起こり得ない」とする記述は誤りです。
